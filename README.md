# AI 記帳 — 設定步驟

Firebase 已經幫你設定好了（專案 `patty-studio-722a4`），用跟薪資 app 同一組帳號登入就能用。

| 檔案 | 用途 |
|---|---|
| `index.html` | app 本體（全部畫面和功能都在這一個檔案） |
| `manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png` | 讓 app 可以「加到主畫面」 |
| `gmail-sync.gs` | 貼到 Google Apps Script，讀 Gmail 的刷卡通知和訂閱收據 |

## 1. Firebase（已完成 ✅）

- 已經填好薪資 app 的 Firebase 設定。
- 記帳資料存在 `users/你的帳號/ledger_entries`、`ledger_bills`、`ledger_settings`，跟薪資 app 的資料放在一起。
- 你原本的安全規則（`users/{userId}/**` 只有本人能讀寫）已經會保護這些資料，**不用改規則**。
- 收入會從 `users/你的帳號/lessons`、`income`、`students` 讀取，**只讀不改**。

**收入怎麼算**（跟薪資 app 的「月收入」一樣）：
- **費瑪**：當月出席、來源是費瑪的課，加總學費
- **Patty**：當月出席的自己學生的課、其他收入、已收的譜費
- **攝影**：當月的攝影收入

月底在 設定 →「結算本月」可以把收入鎖定，之後改簽到也不會影響那個月的帳。

## 3. 放上網路（GitHub Pages，跟薪資 app 一樣）

1. GitHub 新增一個 repository（例如 `ledger`）。
2. 把這個資料夾裡**全部檔案**上傳（`gmail-sync.gs`、`README.md` 放著也沒關係）。
3. repository 的 Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save。
4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/ledger/`。
5. Firebase 主控台 → Authentication → 設定 →「授權網域」，加入 `你的帳號.github.io`（薪資 app 已經加過的話就不用）。

**加到手機主畫面**
- iPhone：用 Safari 打開網址 → 分享 →「加入主畫面」
- Android：Chrome 打開 → 右上選單 →「安裝應用程式」

## 4. 語音 AI 記帳（Gemini）

1. 到 [Google AI Studio](https://aistudio.google.com) 登入 →「Get API key」→ 建立 key。
2. app 裡 設定 →「AI（Gemini）」→ 貼上 key →「測試一下」。

- key 只存在那台裝置，手機和電腦要各貼一次。
- 沒貼 key 也能用，會改用簡單規則辨識（抓金額和關鍵字），小人物也會用預設的話。
- 預設模型是 `gemini-2.5-flash`，Google 改模型名稱的話，在同一頁改就好。

**怎麼記**：按中間麥克風直接說，例如：
- 「晚餐吃拉麵 260」→ 支出・餐飲
- 「昨天全聯用富邦刷 426」→ 支出・生活用品・富邦J卡・日期自動改成昨天
- 「費瑪薪水 25578」→ 收入
- 「存股票 5000」→ 儲蓄・股票

AI 辨識完會先讓你確認，按「確認記帳」才會存進去。存好後，小人物會針對這一筆給你一句分析，表情會跟著預算變：用不到 6 成開心、6～8 成普通、8～9 成擔心、9 成以上哭哭。

**拍帳單**：麥克風對話框右上的相機（或 待繳 →「拍帳單」）。AI 會讀出卡片、應繳金額、結帳日、繳款日；如果帳單金額比 app 裡記到的刷卡多，可以一鍵把差額補記成支出。

## 5. Gmail 自動記帳（刷卡通知、訂閱收據）

**先在每家銀行開「刷卡消費 Email 通知」**（各銀行 app 或網銀裡的「消費通知設定」）。

1. 打開 [script.google.com](https://script.google.com) → 新專案 → 把 `gmail-sync.gs` 全部貼上 → 儲存。
2. 左邊齒輪「專案設定」→ 最下面「指令碼屬性」→ 新增：
   - `GEMINI_KEY`：你的 Gemini API key
   - `TOKEN`：自己想一組密碼，例如 `patty-ledger-8273`
3. 上方函式選 `setup` → 執行 → 第一次會要求授權（Gmail、試算表），按允許。
   它會建立一張「AI 記帳 - Gmail 同步紀錄」試算表，並設定每 15 分鐘自動檢查一次。
4. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：執行身分選「我」，存取權選「任何人」→ 部署 → 複製網址。
5. app 裡 設定 →「Gmail」→ 貼上網址和 TOKEN →「立即同步」。

之後每次打開 app 都會自動抓新紀錄：
- **刷卡通知** → 自動記成支出。AI 會判斷商店和分類，也會依卡名或末四碼對到你設定的卡（所以設定信用卡時，建議填末四碼）。
- **訂閱收據** → 記成「訂閱」支出。如果是新的訂閱，設定頁會先問「要加進來嗎？」，按加入才會開始追蹤。

> 抓不到某家銀行的通知信的話，到 `gmail-sync.gs` 最上面的 `QUERY`，把那家銀行通知信的主旨關鍵字或寄件者加進去。

## 其他說明

- **固定支出、訂閱**：到了每月扣款日會自動記一筆。手動刪掉的那筆不會再自動補回來。
- **刪除**：明細裡每筆往左滑就會出現刪除鍵，刪掉後 4 秒內可以按「復原」。
- **舊資料**：設定 →「匯入 CSV」，可以把 Google 試算表的舊紀錄搬進來（格式說明在那一頁）。
- **提醒**：網頁 app 沒辦法在手機背景推播，所以預算提醒和繳款提醒會在打開 app 時，由小人物和待繳卡片顯示。
- **iPhone 語音**：如果加到主畫面後麥克風不能用，按對話框右上的鍵盤，再用 iPhone 鍵盤上的麥克風說話，效果一樣。
